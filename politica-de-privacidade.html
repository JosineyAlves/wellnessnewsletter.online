A Pastelaria Paris é responsável pelo tratamento de quaisquer dados pessoais eventualmente coletados por meio deste site ou dos canais de atendimento ao cliente.

2. Quais dados podem ser coletados

Este site tem caráter informativo. Não há formulários de cadastro ou coleta automática de dados pessoais identificáveis neste site.

No entanto, caso o cliente entre em contato por telefone ou por meio de links externos disponíveis no site, os seguintes dados podem ser fornecidos voluntariamente:

  • Nome
  • Número de telefone
  • Informações sobre dúvidas ou solicitações relacionadas aos nossos produtos e serviços

Não coletamos dados sensíveis como CPF, RG, dados bancários ou informações financeiras.

3. Finalidade do uso dos dados

As informações eventualmente fornecidas pelos clientes são utilizadas exclusivamente para:

  • Responder dúvidas e solicitações
  • Melhorar o atendimento ao cliente
  • Fins operacionais internos do estabelecimento

Não utilizamos os dados para envio de publicidade não solicitada.

4. Compartilhamento de dados

Os dados fornecidos não são vendidos, alugados ou repassados a terceiros, salvo quando exigido por lei ou determinação judicial.

5. Serviços de terceiros

Este site pode conter links para serviços externos, como o Google Maps, que podem coletar dados de navegação por meio de cookies próprios. Esses serviços possuem suas próprias políticas de privacidade, pelas quais a Pastelaria Paris não se responsabiliza.

6. Segurança dos dados

Adotamos medidas razoáveis para proteger as informações dos nossos clientes contra acesso não autorizado, alteração, divulgação ou destruição. No entanto, nenhum sistema de segurança é absolutamente infalível.

7. Direitos do titular (LGPD – Lei 13.709/2018)

Em conformidade com a Lei Geral de Proteção de Dados, você tem o direito de:

  • Confirmar se tratamos seus dados pessoais
  • Acessar os dados que eventualmente tenhamos sobre você
  • Solicitar correção de dados incompletos ou inexatos
  • Solicitar a exclusão dos seus dados
  • Revogar consentimento a qualquer momento

Para exercer esses direitos, entre em contato pelo telefone (031) 2714-207.

8. Alterações nesta política

Esta Política de Privacidade pode ser atualizada periodicamente. Recomendamos que você a revise sempre que visitar este site. A data da última atualização estará sempre indicada no topo desta página.
